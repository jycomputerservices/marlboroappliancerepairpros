## COMMON QUESTIONS & ANSWERS

**Q: Will these changes hurt my existing rankings?**
A: No. We're adding new content and fixing broken pages. Existing pages will improve, not decline.

**Q: How long until I see results?**
A: Quick wins (FAQ, sticky CTA) = 1-4 weeks. Location pages = 6-12 weeks to full ranking. Problem pages = 4-8 weeks.

**Q: Should I redirect the old Service Area URL?**
A: No redirect needed - the URL stays the same (/service-area). Just fix the 404.

**Q: What if I don't have all the town information?**
A: Start with Marlboro and nearby towns you know best. Add others as you research them.

**Q: Can I do this in phases?**
A: Yes! Start with critical fixes (1-2 weeks), then add content monthly.

**Q: Do I need to buy anything?**
A: Only if you want rank tracking tool (~$100-200/month). Google's free tools sufficient for testing.

## COMMON MISTAKES TO AVOID

❌ **Don't:** Create low-quality location pages (they'll rank poorly)  
✅ **Do:** Make each location page unique and detailed

❌ **Don't:** Use same copy for all problem pages

❌ **Don't:** Ignore phone number inconsistency

❌ **Don't:** Forget internal links

❌ **Don't:** Over-optimize with keywords  
✅ **Do:** Write naturally, keywords will follow

❌ **Don't:** Forget mobile optimization  
✅ **Do:** Test all new pages on mobile
